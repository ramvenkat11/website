An answer is a list of parts. A part is text, HTML or an image.

Text

Text is written as Markdown. Every chat application uses its own dialect, so convert it. Slack and Google Chat need bold and links rewritten. Teams accepts a wider subset.

Images

An image arrives as data, with the type of the image. Upload the image with the chat application’s own file API.

HTML

HTML has no equivalent in Slack, Teams or Google Chat. Convert the HTML to text, or tell the person the answer is available in the GUI. An agent written for a chat audience should produce text and images.
