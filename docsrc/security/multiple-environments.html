Most organizations run their systems in several environments: development, test, staging, production. Search2o supports this with one account per environment.

One account per environment

Each environment needs its own Search2o account and license key. Create an account for each, and start each environment's agent servers with that environment's key. Accounts are fully separate: agents, configuration, conversations and reports never cross between them.

Each environment usually has its own users as well: developers in development, testers in test, and the real user population in production.

Profiles point to the environment's systems

An agent names its profiles, and the profiles carry the endpoints. The same profile names can exist in every account, pointing at that environment's servers: the development database in development, the production database in production. An agent definition therefore moves between environments without change.

Moving agents between environments

Agents are promoted through the REST API: read the agent, its prompts and its description from one account, create a draft in the next, then validate and publish there. These are the same calls the UI uses.
