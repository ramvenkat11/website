Search2o is an agent platform for the enterprise. Developers build task-focused agents, the platform runs them safely against enterprise systems, and people across the organization use them through search and conversation.

Framework. Each agent handles one well-defined task and combines deterministic workflow steps with LLM-driven reasoning. Developers write an agent as a structured definition in JSON with Python expressions, built from twenty commands, and publish it, versioned, to a common system.

Runtime. Agents execute on the Search2o agent server under controlled execution. The agent server calls enterprise systems, holds each agent to its time and LLM-cost bounds, and pauses for user approval before critical actions.

Search. Search matches the meaning of a request to an agent built to handle it, runs that agent and returns its output. Users do not select an agent from a catalog. They ask a question or make a request. Search performs the routing, so hundreds of independent agents work as one system.

Conversations. Follow-up requests continue in the same conversation, where the user can bring in other agents that build on earlier results. Agents remain independent of one another. The user decides the combination.

Interfaces. The same agents can be reached from several places. Users search and hold conversations in the UI or from chat applications. Agent harnesses such as Claude Code can search for and run Search2o agents as part of their own work. A REST API opens the agents to other frameworks and custom applications.

Observability. Every agent run is reported in real time: who asked, what ran, how long it took, any errors and the LLM token cost. Developers also receive a trace of a run when building and debugging an agent.

Administration. Administrators manage the account and its users, with single sign-on and an audit log.

Deployment. The platform has three parts: an agent server, a UI and a cloud service. Your organization runs only stateless agent servers and the UI. The cloud service provides state, search and reporting, and can be shared or dedicated. Customers can turn on end-to-end encryption by supplying their own encryption key.
