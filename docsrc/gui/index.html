A tour of the bundled UI. Every user sees the same search interface. Developers and administrators also see the platform pages their role allows. The source is at github.com/Search2o/ui.

Layout

The left rail has two stacks. Searches lists the user's conversations, pinned ones first, and is where a search starts. Platform lists the pages that build and run the system, grouped as Agents, Profiles, Guardrails, Operations, Reports, Admin and Billing. A user sees only the groups their role allows. The header carries the breadcrumb, the audit log for administrators, the docs icon for asking the documentation a question, and the message icon for reaching Search2o. Every page has a short description at the top. Every configuration field shows its description on hover, the same text as in the Agent runtime reference.
