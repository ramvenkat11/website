The pages every user has: the profile, and docs and help.

Profile

Name, theme (light, dark or system) and password. A new password must satisfy the account's password policy. Integration tokens for chat bots and skills are created and revoked here too; see Connecting a person.

Docs and help

The docs icon in the header asks a question of the documentation, and an AI answers from these pages; see Asking the docs. Help opens a form that sends a message to Search2o support. The reply goes to the email address of the user who sent the message. See Support.
