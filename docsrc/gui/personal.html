The pages every user has: the profile, the notification feed, and help.

Profile

Name, UI theme (light, dark or system) and password. A new password must satisfy the account's password policy.

Notifications

What has changed in the account and who changed it: agents submitted for indexing and the outcome, descriptions removed, tags and titles changed, and configuration parts and profiles created, updated or deleted, with the names of the fields that changed. Filter by type, by user, and by time. Developers and administrators only.

Docs and help

The header links to this documentation. Help opens a form that sends a message to Search2o support. The reply goes to the email address of the user who sent the message. See Support, and see Notifications for what the feed contains.
