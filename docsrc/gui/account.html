Users, authentication and the license. For administrators and the owner.

Users

Everyone in the account, with their role. Filter the list by role. Add users by email; each new user receives an email with a code and chooses a password. Change a user's role, or delete users, from this page. See Users and roles.

Authentication

The session cookie, the password policy, session lifetimes, the allowed email domain, and the emails sent to users. See Authentication.

License

The account name, the status of the license key, and rotation. Owners only. See License rotation.
