Four reports over the last three months of executions. Each report has a date range, a trend chart and a table, and each table row opens into detail.

  • Performance — executions, users, success rate and latency per agent. Open a row for the same figures per version. See Agent performance.
  • Cost — LLM spend per agent. Open a row for the spend per version. See LLM cost.
  • Errors — failures per agent by result code. Open a row for the messages and where each message occurred. See Agent errors.
  • Usage — what each user ran. Administrators only. See User usage.

Choose the range with the control at the top. A window of two days or less is charted by the hour; a longer window is charted by the day.
