The named configurations that agents refer to: LLMs, REST APIs, databases and MCP servers. Each list shows which agents use each profile. A profile that is in use cannot be deleted.

LLM

One profile per model endpoint: the adapter, the URL and headers, the model with its prices, and limits. When a profile is created, the page lists the adapters the agent server knows. See LLM profiles.

API

REST servers with their base URL, headers and connection pool. See API profiles.

Database

Database connections with their connection string and pool settings. See Database profiles.

MCP

MCP servers. The info icon next to each server lists the tools it offers. See MCP servers.
