Search2o gives Claude Code a controlled way to use your company's systems. Claude Code chooses which agent runs; it does not write what runs.

Current architectures

Claude Code first reached company systems through MCP servers, and most installations still do. Claude Code routes every request itself and writes, at run time, the agent code that calls the systems, with the person's access.

Agent gateways came next: an intermediary between Claude Code and the calls it makes, to LLMs and to enterprise systems alike. A gateway checks the calls. The routing, and the agent code, remain Claude Code's.

Skills + Search2o architecture

Search2o is the third arrangement. It becomes the gateway between your enterprise systems and Claude Code, with one big difference: the routing and the code are no longer dynamic in Claude Code. It is Search2o that routes the request and runs the agents. Claude Code makes requests to Search2o, and Search2o finds and runs an agent built for that request.

The first two arrangements share one property: the agent code is written at run time, by the model, and runs with the person's access. A skill guides that code but does not define it. For the resources a person chooses to expose to Claude Code, that is a fair boundary. For company systems it is a poor one.

Search2o gives Claude Code access to published agents instead. An agent is a fixed definition, written by a company developer, validated by execution before publication, versioned, and unchanged at run time. The agent runs on an agent server inside your organization, in a controlled runtime that limits what it can do. Code Claude Code writes locally cannot access the systems behind the agents.

Claude Code sees the request and the agent's output. Everything in between — API responses, database rows, credentials and agent variables — stays inside Search2o. Conversation state is encrypted and saved for follow-up requests. Every run is recorded by agent, version and person.

Together, Agent Skills provide the interface and Search2o provides the controlled execution behind it. People work with Claude Code as they already do, while the company defines what its agents can do and which systems they can access.

Claude Code stands here for every assistant that supports Agent Skills, Cursor among them. The skill is the same.
