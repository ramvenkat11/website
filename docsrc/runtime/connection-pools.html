Every HTTP connection an agent server opens goes through a connection pool: the calls to Search2o Cloud, the LLM calls, and the calls made by api commands through API profiles. Each of those can name its own pool. Administrators define pools on the Connection pools page in the GUI, and the pool named default is used wherever no pool is named. A changed pool reaches every agent server before its next run, and the old pool stays open until the last agent using it finishes.
