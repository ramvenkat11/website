The sys namespace carries what the runtime knows about a run. Four names are always there. Four more reach an agent only when a developer lists them here, so by default an agent sees nothing about the user or the agent server. See Variables and namespaces for how an expression reads them.

Always present

  • sys.inputs is the inputs the agent was called with.
  • sys.query is the user's query.
  • sys.secret reads a secret by name, as sys.secret['name']; see Secret vault.
  • sys.exists answers whether a variable exists, as sys.exists(scope, name); see Python expressions.

Enabled here

cookies deserves care. The cookies carry the user's raw session ID, and an agent that writes the cookies into its output, a variable or a call to an outside system has given that session away. We would suggest enabling cookies only for an agent that needs them, and never letting the value leave the agent server.
