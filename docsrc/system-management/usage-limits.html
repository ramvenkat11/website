Three operations have usage limits: publishing an agent description, AI assist, and documentation questions. Everything else is unlimited. Running agents is never counted.

"Developer" includes administrators and the owner. Every limit counts developers only: end users are never counted. Where a daily and a monthly limit exist, both are enforced. The minimum of 10 on the account ceiling keeps a one-developer account from being held to 2 a day; adding a developer raises the ceiling immediately.

Reaching a limit

A call over a limit is refused before any work is done, with a message naming the limit. A refused call consumes no allowance, and a description rejected by description validation costs nothing. The windows are calendar-aligned in UTC: the day resets at 00:00 UTC, and the month resets on the 1st.

What is not limited

Search, running agents, conversations, the reports, user management and every read are unlimited. The limits on this page are the only usage limits in the system. Runtime limits are a different mechanism: runtime limits bound what one agent run may do, not how often anyone may call.
