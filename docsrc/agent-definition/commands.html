There are 20 commands. Together they cover the agentic workflow: variables, flow control, progress, termination, external systems, LLMs, the user, and output.

Each command has a page in the Command reference, with a table of its fields generated from the agent schema and an example.

Results

Commands that call something set result for the next command to read. The commands that set it are api, db, llm, func, parallel, ask and memory. Other commands leave result unchanged. The next call overwrites it, so save a result you need later with var.

Error handling on a command

api, db and llm accept an onError block. When the command raises an error, the block runs with exc set to the exception, and the function continues with the next command. Without an onError block on the command, the error goes to the function's onError, and then to the caller.
