The GUI is a single-page application bundled with the agent server and served at the server's /ui path. The GUI uses nothing but the agent server's REST API.

Signing in

Open http://127.0.0.1:9020/ui. The first time, click New user / Forgot password? on the sign-in dialog: an email with a code arrives at your registered address, and you enter the code and choose a password. The first user of an account is the account's owner. An Individual account has that single user; from the Evaluation level, add developers and users from the Users page. See Users and roles.

Hosting the GUI elsewhere

The GUI's files live in the server's ui directory and can be served from anywhere, a CDN included. index.html carries a small block of configuration in a <meta name="search2o-ui-config"> tag:

SettingMeaning
apiBaseBase URL of the agent server's REST API. Empty means the same origin as the GUI. When the GUI and the agent server are on different origins, add the GUI's origin to the server's allowed CORS origins.
apiTimeoutSecondsTimeout, in seconds, for REST calls from the GUI. A timeout above 60 is worth keeping: publishing a description is checked by the cloud and can take up to a minute.
notificationDurationSecondsHow long a notification stays visible in the GUI.
docsBaseBase URL of the host that serves the agent JSON schema, with no trailing slash.
defaultSuccessOutputShown when an agent finishes successfully without producing output.

What you will find

Every page is described in GUI pages. In short: users get the search box and their conversations. Developers also get drafts, published agents, profiles and guardrails. Administrators also get users, authentication, agent servers and the license.
