Register for a license key at search2o.com/register, then install the agent server from GitHub with pip.

Register

Search2o is in open beta, and anyone interested is welcome to try it. Registration creates your account and ends by showing the account's license key once. The key connects an agent server to your account in Search2o Cloud. The key belongs with your other secrets, so please store it as soon as registration shows it.

Install

The agent server requires Python 3.12 or later. The source is available at github.com/Search2o/agent-server, and pip installs straight from the repository:

$ pip install git+https://github.com/Search2o/agent-server.git

Cloning first works just as well, and keeps the source at hand:

$ git clone https://github.com/Search2o/agent-server.git $ pip install ./agent-server

The db command uses SQLAlchemy's async engines, so the driver for your database must be installed as well. SQLite works out of the box. The other drivers are optional extras, shown here from a clone; the same extras work in the git+ form as "search2o[postgres] @ git+...".

$ pip install "./agent-server[postgres]" # asyncpg $ pip install "./agent-server[mysql]" # aiomysql, also used for MariaDB $ pip install "./agent-server[oracle]" # oracledb $ pip install "./agent-server[mssql]" # aioodbc, also needs a system ODBC driver $ pip install "./agent-server[db]" # postgres, mysql and oracle together
