Register for a license key at search2o.com, then install the agent server with pip.

Register

Registration creates your account and emails you the account's license key. The key connects an agent server to your account in Search2o Cloud. Keep the key with your other secrets.

Install

The agent server requires Python 3.12 or later.

$ pip install search2o

The db command uses SQLAlchemy's async engines, so the driver for your database must be installed as well. SQLite works out of the box. The other drivers are optional extras:

$ pip install search2o[postgres] # asyncpg $ pip install search2o[mysql] # aiomysql, also used for MariaDB $ pip install search2o[oracle] # oracledb $ pip install search2o[mssql] # aioodbc, also needs a system ODBC driver $ pip install search2o[db] # postgres, mysql and oracle together
