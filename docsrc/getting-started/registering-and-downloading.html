Create your account at tactet.com/gettingstarted, which shows your license key, then install the agent server with pip.

Create your account

Tactet is in open beta, and anyone is welcome to try it. Creating an account is one step. It opens a free account with you as its first user and owner, and shows the account's license key once. The key connects an agent server to your account in the cloud service, so store it with your other secrets as soon as it is shown. You are not asked for a password; you choose one the first time you open the UI.

Install

The agent server and the UI are installed together. They require Python 3.12 or later and are published on PyPI as tactet:

$ pip install tactet

The db command uses SQLAlchemy's async engines, so the driver for your database must be installed too. SQLite works without an extra driver. The other drivers are optional extras of the package:

$ pip install "tactet[postgres]" # asyncpg $ pip install "tactet[mysql]" # aiomysql, also used for MariaDB $ pip install "tactet[oracle]" # oracledb $ pip install "tactet[mssql]" # aioodbc, also needs a system ODBC driver $ pip install "tactet[db]" # postgres, mysql and oracle together

A note on mssql: aioodbc presents an async API but wraps the synchronous ODBC driver underneath. The agent server is fully asynchronous, so a driver that blocks under load can slow the whole server.

To install from the source

Clone the agent server and install it from the clone. The clone does not include the UI.

$ git clone https://github.com/tactetai/agent-server.git $ pip install -e agent-server

Then build the UI, which needs Node.js 22.18 or newer, and copy the build into the agent server's ui directory:

$ git clone https://github.com/tactetai/ui.git $ cd ui && npm install && npm run build $ cp -R dist ../agent-server/tactet/ui

On Windows, copy the dist folder to the same directory. Any web server can serve the UI instead; see How the UI runs. For the license, see License.
