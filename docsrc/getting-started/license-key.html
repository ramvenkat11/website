The agent server needs the account's license key to start. Give it the key through one of two environment variables.

The two variables

# 1. The key itself $ export SEARCH2O_LICENSE_KEY=your-license-key # 2. The path to a file that holds the key $ export SEARCH2O_LICENSE_KEY_FILE=/etc/search2o/license.key

Set exactly one of the two. Setting both is an error. If neither is set, or the key is empty, the server exits at startup.

Rotating the key

An administrator can rotate the license key from the GUI. Running agent servers keep working on the old key until the expiry the administrator chose. Restart them with the new key before then. See License rotation.
