The agent server needs the account's license key to start. The key is supplied through the SEARCH2O_LICENSE environment variable, in one of three forms.

The three forms

# 1. The key itself $ export SEARCH2O_LICENSE=your-license-key # 2. Read the key from another environment variable $ export SEARCH2O_LICENSE=env:SEARCH2O_LICENSE_KEY # 3. Read the key from a file $ export SEARCH2O_LICENSE=file:/etc/search2o/license.key

If SEARCH2O_LICENSE is not set, or resolves to an empty value, the server prints a help message and exits.

Rotating the key

An account owner can rotate the license key at any time from the GUI. Running agent servers keep working on the old key for a grace period. Restart them with the new key before the grace period ends. See License rotation.
