Search2o is a platform for building, running and using AI microagents through search. Developers define agents in JSON with Python expressions and describe each one in plain English. Users type what they need, the matching agent runs, and follow-ups continue the same conversation.

Hybrid architecture

Agent servers are stateless. Search2o Cloud provides the plumbing.
