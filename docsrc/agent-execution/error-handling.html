The runtime handles the errors an agent meets: a failed LLM, API or database call, a tool call the model got wrong, a limit reached, or a command that raised. An agent names what to do on a command's onError block; everything it does not catch ends the run with a result code and a record in the error report.

Where errors are handled

  • Error handling on a command: the onError block every command can carry.
  • fail: ending a run with an error of the agent's own.
  • When something fails: what the person and the client see.
  • Result codes and the error report: how every failure is recorded.
