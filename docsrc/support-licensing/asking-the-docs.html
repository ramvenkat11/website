Ask a question of the documentation in plain English and get an answer back. Answers are written from these pages and from nothing else.

Where to ask

Ask from the docs icon at the top of the GUI. Developers, administrators and the owner can ask. End users cannot.

How an answer is produced

The question is matched against the documentation, and the pages that match become the material for the answer. Nothing outside the documentation is added, so an answer reflects what the product does rather than what is generally true of similar products.

When there is no answer

A question the documentation does not cover comes back with a request to rephrase it. Naming the part of the product you mean usually helps. A question about your own agents or your own account cannot be answered here, because the documentation is the only material available.

One question at a time

Each question is answered on its own; the previous question is not carried forward. Ask a follow-up as a whole question.

Asking the docs is not support. To reach a person at Search2o, use the message icon in the header; see Support.
