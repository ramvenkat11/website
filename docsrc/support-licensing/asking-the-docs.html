Ask a question of the documentation in plain English and get an answer back. Answers are written from these pages and from nothing else.

Where to ask

The docs icon at the top of the GUI opens the documentation, and a question can be asked from the same place. Developers, administrators and the owner can ask. End users cannot.

How an answer is produced

The question is matched against the documentation, and the pages that match become the material for the answer. The answer is written from those pages only. Nothing outside the documentation is added, so an answer reflects what the product does rather than what is generally true of similar products.

When there is no answer

A question the documentation does not cover comes back with a request to rephrase it. Rewording the question usually helps, and naming the part of the product you mean helps more. A question about your own agents or your own account cannot be answered here, because the documentation is the only material available.

What asking the docs does not do

Each question is answered on its own. A follow-up that depends on an earlier answer is best asked as a whole question again, because the previous question is not carried forward.

Asking the docs is also not support. To reach a person at Search2o, the help icon opens a form that sends a message; please see Support.

Limits

Documentation questions are limited to 10 a day and 100 a month for each developer. Usage limits has the full table and says what happens when a limit is reached.
