Help is reached from inside the GUI. Every message carries the account it came from.

Sending a message

The help icon in the header opens a form with a subject and a message. Developers and administrators can use the form. The message goes to Search2o support with the sender’s email as the reply address, so the answer comes straight back to the person who asked. Messages are kept for a year.

What to include

For a problem with an agent, include the three things that let us reproduce the problem: the agent name and version, the query, and what the validation trace or the error report shows, meaning the error message and the path of the command. For an indexing problem, include the notification that reported the failure. For a configuration problem, name the part or profile and the field.

Where to look first

  • Error report — every failed execution, by agent, version, result code and message, with the command in the agent where the failure happened.
  • Notifications — indexing failures and recent changes to configuration and profiles.
  • Validation trace — run the draft against a query and read every step.
  • Agent servers — what each running server found when the server loaded the configuration, including allowlist entries the server could not resolve.

Outside the product

Email info@search2o.com. The agent server's source is at github.com/Search2o/agent-server.
