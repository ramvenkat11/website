Agent server

The search2o package on PyPI is published under a proprietary license. Use requires a valid, ongoing authorization from Search2o. The license text ships with the package and is at search2o.com/ip/license.txt.

GUI

The GUI is bundled with the agent server under the same license.

Cloud service

Search2o operates Search2o Cloud, and the cloud's code is not published either. Only the agent server uses the cloud's API; the license prohibits calling the API directly.
