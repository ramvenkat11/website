The agent server source is available on GitHub, and the software is proprietary.

Agent server

The agent server and the UI are installed together with pip install tactet from PyPI; see Creating an account and downloading. The source is at github.com/tactet-ai/agent-server for the agent server and github.com/tactet-ai/ui for the UI. Use requires a valid, ongoing authorization from Tactet. The license text is the LICENSE file in the repository.

Contributions

External code contributions and pull requests are not accepted at this time. Bug reports, feature requests, documentation feedback and security reports are welcome; the repository's CONTRIBUTING file says where each goes.

UI

The UI is bundled with the agent server under the same license.

Cloud service

Tactet operates the cloud service. Only the agent server uses the cloud service's API; the license prohibits calling the API directly.

The cloud service currently operates from the US East region, so an agent server in US East sees the lowest latency. Other regions will follow.

Pricing

An account starts free. Billing starts only when the owner upgrades to the paid service from the Account page. See Pricing.
