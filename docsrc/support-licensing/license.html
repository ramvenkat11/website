The agent server source is available on GitHub, and the software is proprietary. Availability of the source does not make the software open source.

Agent server

The agent server, with the bundled GUI, is installed with pip install search2o from PyPI; see Creating an account and downloading. The agent server source is available at github.com/Search2o/agent-server. Use requires a valid, ongoing authorization from Search2o. The license text is the LICENSE file in the repository.

Contributions

External code contributions and pull requests are not accepted at this time. Bug reports, feature requests, documentation feedback and security reports are all welcome; the repository's CONTRIBUTING file says where each goes.

GUI

The GUI is bundled with the agent server under the same license.

Cloud service

Search2o operates Search2o Cloud. Only the agent server uses the cloud's API; the license prohibits calling the API directly.

Search2o Cloud currently operates from the US East. You will see the lowest latency if you run the agent server in the US East. We will expand to other regions in the future.

Pricing

Individual use and team evaluations are free. See Pricing for the Team service.
