The agent server is source available: the code is public on GitHub, and the software is proprietary. Availability of the source does not make the software open source.

Agent server

The source is at github.com/Search2o/agent-server and installs with pip straight from the repository; see Registering and downloading. Use requires a valid, ongoing authorization from Search2o. The license text is the LICENSE file in the repository.

Contributions

External code contributions and pull requests are not accepted at this time. Bug reports, feature requests, documentation feedback and security reports are all welcome; the repository's CONTRIBUTING file says where each goes.

GUI

The GUI is bundled with the agent server under the same license.

Cloud service

Search2o operates Search2o Cloud, and the cloud's code is not published. Only the agent server uses the cloud's API; the license prohibits calling the API directly.

Beta

Search2o is in open beta. There is no charge during the beta period. See Pricing for what follows.
