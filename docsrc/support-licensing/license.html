The agent server is source-available. The cloud service is not published.

Agent server

The search2o package on PyPI is published under a source-available license. The source can be read, built and modified for use with a Search2o account, and use requires a valid, ongoing authorization from Search2o. The license text ships with the package and is at search2o.com/ip/license.txt. The repository is github.com/Search2o/agentserver.

GUI

The GUI is bundled with the agent server under the same license. The GUI's source will be made available on the same terms.

Cloud service

Search2o operates Search2o Cloud, and the cloud's code is not published. Only the agent server uses the cloud's API; the license prohibits calling the API directly.

Beta

Search2o is in open beta. There is no charge during the beta period. See Pricing for what follows.
