Agents are edited in a code editor that understands the agent schema: commands, fields and blocks. The editor provides completion, context-sensitive help and AI assist.

Completion

The editor knows which commands may appear where, and which fields each command takes. Typing a double quote inside the definition opens the suggestions for that location: the commands allowed in a block, or the fields of the command you are in. Each suggestion carries the field's description. The description is the same text that appears in the Command reference.

F1

The F1 key opens the full list of commands, grouped as in the reference, with a description of each command. Choosing a command inserts the command with its starter fields.

Errors as you type

The editor validates the definition against the schema while you type. Unknown commands, unknown fields, values of the wrong type and missing required fields are underlined, with the same message the server would give. Many mistakes are caught before validation runs.

Controls

The controls for the draft sit above the editor: the draft's name, title, tag and validation query, and the buttons to validate and publish. AI assist is a panel beside the editor; see AI assist.
