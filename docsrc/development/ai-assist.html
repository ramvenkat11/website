AI assist writes a complete agent definition in Search2o's JSON format from a description of what the agent should do.

Using it

Describe the agent in a sentence or a paragraph, then ask. The result is a full definition. Paste the definition into the editor, then refine, validate and publish it. Sample requests:

  • Create an agent with a RAG workflow
  • Create an agent with tool calling with functions
  • Create an agent with tool calling with MCP
  • Create an agent calling other agents
  • Create an agent with human in the loop

The more specific the request, the closer the result is to an agent that runs unchanged. It helps to say which profiles to use, which API to call, and what the user will ask.

What it knows

AI assist knows the agent schema, the commands, and the workflows listed below. AI assist does not know your configuration. Check that the profile names, API paths and table names in the result are the ones you have, or state them in the request.

Workflows it can write

Every common LLM workflow is a few commands in Search2o, and AI assist knows each shape. Ask for a workflow by name, or combine several.

  • RAG — retrieve the passages relevant to the question with db or api, put the passages in the prompt, and have the llm answer only from them.
  • Tool calling with functions — name functions of the agent in the llm command's functions field. The model reads the descriptions and typed arguments of those functions. The runtime runs each call and feeds the result back until the model answers.
  • Tool calling with MCP — register a server under Profiles → MCP and name the server in the llm command's mcp field, either for all of the server's tools or for a chosen few.
  • Deep agents — an orchestrator that searches for the agent that can do the work and invokes that agent. The invoked agent's output streams to the user as if the user had run the agent directly.
  • Human in the loop — ask pauses the agent with a form and resumes with the answers, even days later or from another device.
  • Parallel calls — put independent work in separate functions and run those functions at once with parallel. The results come back keyed by function name.

Nothing is saved

A request to AI assist reads nothing from your account and stores nothing. The generated definition is yours to keep or discard. Until you paste the definition into the draft, nothing has changed.
