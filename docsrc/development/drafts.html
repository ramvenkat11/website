Agent development begins with a draft. A draft is private: only the developer who created it can see it.

What a draft holds

  • The agent's name and title.
  • The agent definition, as a JSONC document.
  • The agent's prompts.
  • The agent's const: a JSON object the agent reads as const.name, stored encrypted so that the cloud cannot read it.
  • The profiles the agent uses. Draft with AI reads these.
  • The agent's run limits: the most time and the most LLM spend one run may take.
  • The agent's tag.
  • A validation query: a typical request the agent should handle. Validation runs the draft against it.

New agents and changes

A draft is created for a new agent, or from a published agent to change it. The definition, the prompts and the const change only through a draft: edit, validate, publish. The title, the run limits and the tag can also be changed on the agent's page. A draft for a new agent can be renamed until it is published. A draft of an existing agent keeps the agent's name.

The draft's conversation

Each draft has its own conversation, which validation runs use. It is not listed with the user's conversations, and it is removed when the draft is published or deleted. Validation runs do not appear in reports.

Limits

A developer may hold 10 drafts on the Free plan and 100 on the Paid plan. Drafts can be deleted in bulk from the drafts list. Deleting a draft never touches a published agent.
