An LLM profile is one model at one vendor: how to reach the model and what it costs. Agents name the profile in the llm command. To use another model, define another profile.

Settings

Model prices

Prices are per million tokens. The cost report and each agent's LLM cost limit are computed from them.

Dynamic values

url, the values in headers, and the string values in additionalParams are dynamic strings, evaluated for every call with the same rules as an agent expression. A secret read at call time keeps the key out of the configuration: { f"Bearer {sys.secret['OPENAI_API_KEY']}" }.

Seeded profiles

A new account has eight profiles. Five reach a vendor and read the key from the agent server's environment: OpenAI (gpt5_mini, and gpt_image for image generation), Anthropic (claude_haiku) and Gemini (gemini_flash, and gemini_image for image generation). Three reach a model served on the agent server's own machine and do not need a key: ollama_qwen25, vllm_qwen25 and sglang_qwen25, for Ollama, vLLM and SGLang at their default ports. Edit the model and the prices to match your contracts.

Other vendors

A model you host with Ollama, vLLM or SGLang needs only a profile that names the ollama, vllm or sglang adapter; see LLM vendors. Any endpoint that speaks the OpenAI, Anthropic or Gemini protocol needs only a profile with the endpoint's URL. Any other endpoint needs an adapter.
