A database profile describes a database connection that agents query through the db command. The profile holds the connection string and the pool settings for that connection.

Settings

Connection pool

An agent server keeps one pool per profile. When the connection string changes, for example after a vault secret is rotated, the old pool is closed and a new one opened. With poolKey set, there is one pool per distinct value of the expression, for example one per user. A pool that has not been used for idleTimeout seconds is closed.

The connection string names an async SQLAlchemy driver, which must be installed in the agent server's environment: postgresql+asyncpg://..., mysql+aiomysql://..., oracle+oracledb://..., mssql+aioodbc://..., sqlite+aiosqlite:///path. The connection string is a dynamic string, so the password can come from sys.secret.
