Reusable system and user prompts that agents refer to by name in the prompt command. The same wording does not have to be repeated in every agent, and the wording can be changed once for all agents that use the profile.

Settings

A prompt marked dynamic is evaluated as a dynamic string in the agent's context every time the prompt is used, so the prompt can refer to variables the agent has set. A static prompt is used verbatim. Static prompts are faster, and safer for text that contains braces.
