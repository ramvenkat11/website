An API profile describes a REST server that agents call through the api command. The profile holds the server's base URL, the headers sent on every call, and the connection pool used.

Settings

The URL and the header values are dynamic strings, so credentials can come from sys.secret instead of being stored in the profile. A header set on the command replaces the profile's header of the same name only when the profile marks that header as one a command may override; otherwise the call fails. A header the profile does not have is added only when the profile allows commands to add headers; otherwise the call fails.
