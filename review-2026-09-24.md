# Site and docs review, 2026-09-24

Nine parallel reads of every site page, every docs page, the 86 generated tables and the four
legal pages. Findings only; nothing below has been changed except the two marked FIXED (my own
leftovers). Items marked VERIFIED were checked against the product code. Items marked "Ram's
wording" are flagged for the record, not judged.

## A. Wrong or self-contradictory

1. docsrc/profiles/api-profiles.html:6 — "Headers set on the command are added to the profile's headers. Where both set the same header, the profile's value wins." — VERIFIED wrong (search2o commands/api.py merge_headers): a command header replaces a profile header only when the profile marks that header `override`, otherwise the call fails; a new header is added only when the profile's `canAddHeaders` is on, otherwise the call fails.
2. docsrc/agent-definition/python-expressions.html:63 — refused example "four nested list comprehensions" — VERIFIED wrong: the check refuses depth > 4, so four is allowed; the example should be five.
3. docsrc/search/search-quality.html:31 — "The easiest and hardest catalogues here are seven points apart, and both are 100-agent catalogues" — VERIFIED against the page's own tables: seven points is right (91.0 vs 83.8) but the easiest, the university, is a 50-agent catalogue.
