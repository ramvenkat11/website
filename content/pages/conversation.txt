# Conversations let agents build on each other.

In Tactet, an agent does not call another agent directly. Instead, conversations carry the work from one agent to the next.

A conversation is unique and belongs to one user. A conversation is encrypted and stored automatically when an agent runs successfully.


## What a conversation keeps

When an agent ends successfully, the platform saves the conversation’s state automatically. The next run in the conversation, whether by the same agent or another, starts from that state.

The prompts. A prompt is a data structure that maintains the message thread with an LLM in a standard format. An agent can use multiple prompts and each prompt has a name and scope.

The variables. The conversation variables that every agent in the conversation can read and write, plus each agent’s own variables. An agent stores information that later agents will need in a conversation variable.

A conversation also keeps additional internal information that is used for other purposes, such as showing the conversation history and restoring an agent that is waiting for user input.


## Prompts carry the exchange

A prompt is what an llm command sends to a model: system text, user text, and the history of the exchange so far. Each prompt has a scope that determines how long its history lasts and which agents share it.

conversation (the default). One history for the whole conversation, shared by every agent that has a prompt with the same name. A second agent can see what was said to the first.

agent. The agent’s own history for the whole conversation. Other agents in the same conversation cannot see it.

local. A history for one run, empty at the start of every run. Use it for one-off tasks, such as classifying or summarizing, where earlier runs should not affect the answer.

Each prompt has a name, and that name connects agents. A second agent continues the first agent’s exchange only when its prompt has the same name and uses the conversation scope. A prompt with a different name starts its own history. Prompts explains how prompts are written and evaluated.


## Agree on names

Agents build on each other through names: the prompt name that continues the exchange, and the conversation variables that pass one agent’s findings to the next. The system does not enforce these names, so an enterprise must agree on them before its agents can work together.

A naming scheme can be short: one standard prompt name, such as chat, for every agent’s exchange with the user, and one name for each item agents pass to each other, such as conv.trip, conv.customer, or conv.order, along with what it holds. An agent that follows the scheme fits into any conversation in the account. An agent that invents its own names starts with nothing and leaves nothing the next agent can find. See Agreeing on names in the documentation.


## A follow-up can go to a different agent

A follow-up in a conversation is searched like a new request. If it belongs to another agent, that agent runs next with the conversation’s state already in place. If no new agent matches, the agent that answered last answers again.

What an interface does with the matches depends on its search behavior. The default setting in the UI runs the best match immediately; it can be set to show the matches, including the last agent that ran.

The client always decides which agent runs next. An agent cannot run another agent. A request with several parts is coordinated from outside: an agent harness with the Tactet skill splits the request, sends each part through search and execAgent in the same conversation, and combines the results into one answer. See How agents build on each other.

## Ask for something, then follow up

The search and conversation demo runs in a live Tactet account with 200 agents, from human resources and finance to engineering and sales. Ask for something, then ask a follow-up and watch the conversation move to another agent that knows what the first one found. It is configured to run an agent automatically if the agent server returns a single match. Otherwise, it shows the options.
