## The agent server and the UI are always free

The Tactet agent server and UI have no license fee. Both run in your organization. The agent server is stateless and runs either standalone or in a load-balanced cluster. Install the agent server and the UI with pip install tactet.

Both the agent server and UI are source-available and can also be installed from the source.


## The shared cloud service is currently free

The agent server stores state in the cloud service. The shared cloud service is currently free to use. A paid service is expected in early 2027, at $40 per user per month. You can then upgrade from the Account page.


## Dedicated cloud service

A dedicated cloud service will be offered in the future as an enterprise solution, with custom pricing.


## Usage limits and restrictions

Your free account has usage limits. If they get in the way of your work, send us a message from the UI and we will raise them. Please coordinate with us before running load or stress tests.
