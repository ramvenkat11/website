Search2o application server
    A box with four parts: Agent framework, Controlled runtime, Search, Observability

    Developer icon produces to Agent framework: Build, validate, publish agents
    Developer icon produces to Search: Describe agents (A text clob showing an agent description)
    Developer icon consumes reports from Observability

    User icon talks to Search: Makes a search request (A text clob showing a request), Receives an agent back (show agent title)
    User icon talks to controlled runtime: Sends execAgent(conversationId, request), Receives agent output.
    Users can consume from a chatbox or from agent harness - both will use the above two interactions.
