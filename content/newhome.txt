Let your users converse with hundreds of microagents

Microagents are small, task focused agents that run on a server for different users.

Developers build, validate and publish microagents on the agent server. They describe when to use each one in plain English. Users never learn them.

Users just start a conversation with a request. The agent server finds the right microagent with semantic search, and runs it on that request. Follow‑up requests can bring in other agents, and build on previous results.

The agent server keeps every run safe, bounded and observable.
