# About Search2o

Search2o takes an opinionated approach: search is how users consume agents.

By centralizing search as the orchestration layer and building a framework and runtime around that idea, Search2o simplifies and standardizes how agents are built and consumed.

Search2o's JSON/Python framework lets developers build agents declaratively. Instead of hardwiring coordination between agents, developers build focused agents with clear, stated responsibilities. These plain-English descriptions are used by search to match each user query to the right agent.

Users don't need to know which agents exist in the system. They discover them by entering their request and letting the system find the right agent. By progressively adding more requests to the same conversation, they can combine the capabilities of multiple agents dynamically to reach their end goal.

Because agents are focused and purpose-built, the system remains understandable and operable as it evolves.
