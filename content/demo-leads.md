# Demo page introductions

## Draft with AI (html/demo-draft.html)

Heading: Describe an agent and AI will draft it

Draft with AI writes or edits an agent based on your description. This feature is available from the agent editor page in the UI. Since Search2o agents are structured with a schema definition, AI generates a fully formed agent. AI doesn't write the prompts or profiles as they are defined outside the agent draft. 

## Chat with agents (html/demo-search.html)

Heading: One conversation, many agents

This demo runs in a live Search2o account with 200 agents. Each of the 200 agents was generated by AI. They use mock data, but otherwise, do a full agent run. 

This demo is intended to illustrate (a) How agents work (b) How search matches a request to an agent and (c) How multiple agents build on each other in a conversation. 

In this demo, if a request matches a single agent, it runs automatically. If it matches two agents, they are shown to the user. See the search page for how often two agents are shown. In the bundled UI in the product, this behavior can be customized in many different ways. 

## Trace an agent run (html/demo-trace.html)

Heading: Trace an agent as it runs

This demo shows what a developer sees while validating an agent. This uses the same 200 agents from the conversation demo. 

Trace displays voluminous information including each system call's input and output. You can use the filters to turn on and off the parts of the trace output that you want to see. Sensitive information is masked in the trace output. 

Trace and validation are integrated with the agent editor in the UI.
