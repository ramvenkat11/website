## The agent server is always free

The Search2o agent server has no license fee. It is [stateless](docs/runtime/overview.html) and runs in your organization, either standalone or in a load-balanced [cluster](docs/system-management/agent-servers.html). Install the server and UI with [`pip install search2o`](docs/getting-started/registering-and-downloading.html#install).

Both the [agent server](https://github.com/Search2o/agent-server) and [UI](https://github.com/Search2o/ui) are source-available and can also be [installed from source](docs/getting-started/registering-and-downloading.html#to-install-from-the-source).

## Search2o Cloud is free during beta

The agent server stores state in Search2o Cloud. The cloud service is in beta and free to use. It becomes a paid service at general availability, planned for January 2027. You can then upgrade from the Account page.

Search2o cloud will have usage based pricing. 

## Private cloud 

Private cloud will be offered as an enterprise solution and it will have custom pricing.  

## Usage limits and restrictions

Your free account has usage limits. If they get in the way of your work, send us a message from the UI and we will raise them. Please coordinate with us before running load or stress tests.

## Please tell us what you need

We are committed to the success of your project. If you have questions, find a bug or need a feature, contact us. When you are signed in, send a message from the message icon in the UI. Before you have an account, use the [contact page](about.html#contact). We can also build the agents and set up the system for you; see [Consulting](about.html#consulting).
