Search

Users do not choose agents. They say what they need.

Search reads a request in plain language and returns the agent built to handle it. Here is the exchange, as the bundled GUI, a chat bot or your own interface makes it.

Search works from meaning, not words. A request and a description need not share a word, or a language. A result takes less than half a second, and a thousand agents are searched as quickly as a hundred.

The description is what search matches against

When an agent is published, its developer describes it in plain language. Search indexes the description within half a minute. This is the description the request above matched.

A description is written for the person who will type the request. It says what the agent does for the user: the questions it answers, the actions it takes, what it leaves to others. Two to five sentences is typical. A description that names only the mechanism, such as “calls the travel API and summarizes the JSON”, matches poorly, because nobody asks for a mechanism; search returns it to the developer with an explanation of what to change. When two agents overlap by accident, a request in the shared territory returns both, and sharper descriptions separate them. See describing an agent.

A conversation can move from agent to agent

A follow-up in a conversation is searched like a new request. When it belongs to another agent, that agent runs next, with the conversation’s state and history in place. When nothing new matches, the agent that answered last answers again.

What an interface does with the matches is its own search behavior: the bundled GUI runs the best match at once; your own interface can offer the two best as a choice. Tags split an account’s agents into pools, one for the help desk and one for finance, and a search names a pool or searches them all.

Search quality

Measured on 15,000 questions, against the live service

Six catalogs of agents, from a university to a thousand agents across fifty business areas. 15,000 questions, each with a known right agent. Every question went through the search we ship.

The right agent comes first 84% to 91% of the time, depending on the catalog, and is one of the first two 92% to 97% of the time. A request about something else entirely is always refused; a request about the customer’s own world that no agent covers is refused 82% to 86% of the time. A search takes about 200 milliseconds. A thousand agents score within a point of a hundred. What separates the easy catalogs from the hard ones is how far apart their agents sit, and the descriptions decide that. The search quality page has every table and the conditions behind each number.
