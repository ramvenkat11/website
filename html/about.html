Rethinking search

Traditional search retrieves information and is judged on precision and recall. Search2o was built on a simple idea: what if search found and ran an executable to fulfill the user’s request?

That is search that executes.

In Search2o, those executables are agents — programs that combine deterministic code with LLM-driven reasoning and decisions.

For search that executes to work in an enterprise, agents need to run safely, call enterprise systems, and pause for user approval before taking critical actions. The system also has to accommodate change: new agents can be added and existing ones removed as requirements evolve.

That implies more than search alone: a framework for defining agents, a runtime for executing them safely, a publishing model for making them available, conversations for follow-ups, administration, and an end-user interface.

A hybrid cloud architecture makes the system easier to deploy and maintain without depending on existing application infrastructure. Administrators only need to run stateless agent servers in their environment. Encryption protects sensitive information in the cloud, including queries, conversations, short- and long-term memories, and agent descriptions.

Developers create focused agents with clear responsibilities and publish them to a common system. Users can get started quickly because they already understand search.

Company
