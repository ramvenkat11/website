Getting started

Up and running on your laptop

Register for a license, install the agent server, and run it on your local machine — preferably with one LLM key. Build and publish your first agent, then move the server to a common place for your team.

Register

Registration gives you a Search2o license for the open beta. There is no charge during the beta period.

We confirm registrations by email and send your license key to the address above.

Download the agent server

The agent server is a Python 3.12+ package. Install it wherever you want agents to run — your laptop is the right place to start.

$pip install search2o

The package is published on PyPI under a proprietary license; see License.

Run the server

Set up the license key

Add the license key from your registration email to the server’s configuration. The key is what connects your agent server to Search2o Cloud.

Start the server

Start the server on your local machine with the license and, preferably, one LLM key. The server is stateless — all conversation state lives, encrypted, in Search2o Cloud, so you can stop and restart it freely.

Create your first agent

Build the agent in the JSON/Python framework: an agent is a list of functions, and a function is a list of commands.

Trace and debug the agent live from the developer UI as it runs, then publish it when it behaves the way you want.

Describe your agent, then search

Describe what the agent does in plain English. That description is what search uses to match user requests to your agent.

Now run a search — type a request the agent should handle and watch it match, execute, and stream its result.

Bring your team

Add users from the admin UI. When you’re ready, shut the server down on your laptop and start it in a common place in your organization — because the server is stateless, nothing else has to change.

Read the docs

The full documentation is at search2o.com/docs — the agent framework, all 23 commands, configuration, reports and administration — and the application links to it from every page.

Stuck at any step? Email info@search2o.com from your registration address and we’ll help you get running.
