Getting started

Up and running on your laptop

From registration to your first running agent, on your laptop. This page has everything you need; the docs go deeper on every topic.

Register

Search2o is in open beta, and anyone interested is welcome. The beta is free for three months, and nothing is charged unless you choose the paid service. Registration ends by showing your account’s license key once — please store it with your other secrets.

Download the agent server

The agent server is a Python 3.12+ package, installed from GitHub. Install it wherever you want agents to run — your laptop is a good place to start. Pip installs straight from the repository, or clone the repository first and install from the clone:

terminal
$ pip install git+https://github.com/Search2o/agent-server.git
# or clone, then install from the clone
$ git clone https://github.com/Search2o/agent-server.git
$ pip install ./agent-server

SQLite works out of the box. For another database, install from a clone with the matching extra — pip install "./agent-server[postgres]" — likewise mysql, oracle or mssql.

Run the server

Set up the license key

The license key from registration connects your agent server to Search2o Cloud. Give the server the key in one of two ways:

terminal
$ export SEARCH2O_LICENSE_KEY=your-license-key
# or point at a file that holds the key
$ export SEARCH2O_LICENSE_KEY_FILE=/path/to/license.key

Please set only one of the two. With neither set, the server exits at startup.

Set up one LLM key

A new account comes with LLM profiles for OpenAI, Anthropic and Gemini. Set the environment variable for the vendor you use: OPENAI_API_KEY, ANTHROPIC_API_KEY or GEMINI_API_KEY. One key is enough, and Search2o is not limited to these vendors.

Start the server

terminal
$ SEARCH2O_LICENSE_KEY=your-license-key ANTHROPIC_API_KEY=sk-ant-... search2o

The server is stateless — conversation state lives, encrypted, in Search2o Cloud — so you can stop and restart the server anywhere. Just make sure the APIs and databases your agents call are reachable from where the server runs.

Further command line options go to Uvicorn, so --host and --port work as usual.

Open the GUI

Go to http://127.0.0.1:9020/ui and sign in with the email address and password you registered with. The first user of an account is the account’s owner.

The server also serves the OpenAPI schema at /openapi.json, Swagger UI at /docs and ReDoc at /redoc. All of these paths can be changed, or removed, from the GUI.

Create your first agent

Open Agents → Drafts and create a new draft. Give the draft a name and a title: agents refer to each other by name, and users see the title. Then paste this agent into the editor. The agent sends the user’s query to an LLM and streams the answer back:

A minimal agent
{
  "functions": {
    "main": {
      "commands": {
        "prompt": {
          "system": "You are a helpful assistant. Answer briefly.",
          "user": "{ sys.query }"
        },
        "llm": { "profile": "claude_haiku", "streamOutput": true }
      }
    }
  }
}
  • main is the function that runs first.
  • prompt sets the system prompt; sys.query is the text the user typed.
  • llm sends the prompt to the claude_haiku profile and streams the answer. Change the profile to gpt5_mini or gemini_flash if that is the key you set.

Enter a validation query such as What is the capital of France, in one word? and validate. The draft is checked and run against that query, and the execution trace shows each command with what came back. When the draft validates, publish it.

AI assist in the editor writes a full agent from one sentence — a faster path once you have seen the shape.

Describe your agent, then search

Open the published agent and write its description in plain English — for example Answers general knowledge questions in a sentence or two. Search matches user requests against this description. Publishing the description indexes the agent, and a notification tells you when indexing is done.

Now switch to the search box and type a question the agent should handle. The agent matches, runs, and streams its answer. Ask a follow-up — the conversation continues with the context of the first answer.

Bring your team

Add users with roles from the Account section. When you’re ready, start the agent server in a common place in your organization — or share the license key, and colleagues can run servers on their own laptops. Because the server is stateless, nothing else has to change.

Read the docs, or ask a question

The docs icon at the top of the GUI opens the full documentation beside your work. From there you can also ask a question of the docs in plain English and get an answer.

The same pages are on the web at search2o.com/docs: the agent framework, all 23 commands, configuration, reports and administration.

Stuck at any step? Email info@search2o.com from your registration address and we’ll help you get running. Once the GUI is open in your browser, the help icon there is the best way to contact us.
