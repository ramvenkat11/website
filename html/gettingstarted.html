Getting started

From your laptop to production

Create your account

Download the agent server

Install the agent server with the bundled GUI:

terminal
$ pip install search2o

Run the server

Use an LLM key

A key from one of the three major vendors is enough: OPENAI_API_KEY, ANTHROPIC_API_KEY or GEMINI_API_KEY. See the docs for the details, and for other LLMs.

Start the server

macOS / Linux
$ SEARCH2O_LICENSE_KEY=your-license-key ANTHROPIC_API_KEY=sk-ant-... search2o
Windows PowerShell
PS> $env:SEARCH2O_LICENSE_KEY="your-license-key"
PS> $env:ANTHROPIC_API_KEY="sk-ant-..."
PS> search2o

Open the GUI

Open http://127.0.0.1:9020/ui and click New user / Forgot password on the sign-in dialog. Enter the email you used in step 1; an email with a code arrives. Enter the code, choose a password, and sign in.

Create your first agent

Open Agents → Drafts and create a draft. AI assist writes a full agent from one sentence — or paste this one into the editor:

A minimal agent
{
  "functions": {
    "main": {
      "commands": {
        "prompt": {
          "system": "You are a helpful assistant. Answer briefly.",
          "user": "{ sys.query }"
        },
        "llm": { "profile": "claude_haiku", "streamOutput": true }
      }
    }
  }
}
  • main is the function that runs first.
  • prompt sets the system prompt; sys.query is the text the user typed.
  • llm sends the prompt to the claude_haiku profile and streams the answer. Change the profile to gpt5_mini or gemini_flash if that is the key you set.

Enter a validation query — What is the capital of France, in one word? — and validate. The trace shows each command and what came back. Then publish.

Describe your agent, then search

Publishing offers to take the description — you can also open the agent later and add it. Write it in plain English, for example Answers general knowledge questions in a sentence or two.

Search matches requests against the description, and publishing the description indexes the agent.

Type a question in the search box. The agent matches, runs, and streams its answer. Follow-ups continue the conversation.

Call your systems

The APIs and databases your agents call must be reachable from where the server runs.

Database drivers must be async; see the docs.

Ask a question

From the docs icon in the GUI, ask a question in plain English; AI writes the answer from the documentation at search2o.com/docs.

Stuck? Email info@search2o.com and we’ll help. Once the GUI is open, its help icon is the best way to reach us.

Bring your team

When you’re ready for your team, request an Evaluation license from the Account page in the GUI. You are notified of the approval by email within one business day.

Then start the server in a common place — nothing else has to change.

See Pricing for what each level includes.

Upgrade to the paid service

When your team is ready, upgrade to the paid service from the Account page in the GUI.

If you would like to contact us, we are one click away from the help icon.
