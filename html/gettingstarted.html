Getting started

Up and running on your laptop

A laptop is enough to start. When you are ready to show it to your team, upgrade it to ‘Evaluation’ from the Account page in the GUI and run the server from a common place.

Register

Before you start, you need a license key. Register to get one.

Download the agent server

The agent server is a Python 3.12+ package. Install it from GitHub:

terminal
$ pip install git+https://github.com/Search2o/agent-server.git
OR
terminal
$ git clone https://github.com/Search2o/agent-server.git
$ pip install ./agent-server

Run the server

Set up the license key

The license key connects your agent server to Search2o Cloud:

terminal
$ export SEARCH2O_LICENSE_KEY=your-license-key
OR
terminal
$ export SEARCH2O_LICENSE_KEY_FILE=/path/to/license.key

Set up one LLM key

Set the key for the vendor you use: OPENAI_API_KEY, ANTHROPIC_API_KEY or GEMINI_API_KEY. One is enough.

Start the server

terminal
$ SEARCH2O_LICENSE_KEY=your-license-key ANTHROPIC_API_KEY=sk-ant-... search2o

Open the GUI

Open http://127.0.0.1:9020/ui and click New user / Forgot password? on the sign-in dialog. An email with a code arrives at your registered address; enter the code, choose a password, and sign in.

REST API

The server also serves the OpenAPI schema at /openapi.json, Swagger UI at /docs and ReDoc at /redoc.

Create your first agent

Open Agents → Drafts and create a draft. AI assist writes a full agent from one sentence — or paste this one into the editor:

A minimal agent
{
  "functions": {
    "main": {
      "commands": {
        "prompt": {
          "system": "You are a helpful assistant. Answer briefly.",
          "user": "{ sys.query }"
        },
        "llm": { "profile": "claude_haiku", "streamOutput": true }
      }
    }
  }
}
  • main is the function that runs first.
  • prompt sets the system prompt; sys.query is the text the user typed.
  • llm sends the prompt to the claude_haiku profile and streams the answer. Change the profile to gpt5_mini or gemini_flash if that is the key you set.

Enter a validation query — What is the capital of France, in one word? — and validate. The trace shows each command and what came back. Then publish.

Describe your agent, then search

Write the agent’s description in plain English — for example Answers general knowledge questions in a sentence or two. Search matches requests against the description. Publishing the description indexes the agent.

Type a question in the search box. The agent matches, runs, and streams its answer. Follow-ups continue the conversation.

Call your systems

The APIs and databases your agents call must be reachable from where the server runs.

Databases are reached through async drivers; see the docs.

Ask a question

From the docs icon in the GUI, ask a question in plain English; AI writes the answer from the documentation. The documentation itself is on the web at search2o.com/docs.

Stuck? Email info@search2o.com and we’ll help. Once the GUI is open, its help icon is the best way to reach us.
