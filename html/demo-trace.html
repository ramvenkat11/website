Trace an agent as it runs

This demo shows what a developer sees while validating an agent. It uses the same 200 agents as the Chat with agents demo.

A trace shows a great deal of detail, including the input and output of each call the agent makes. Use the filters to show or hide each kind of line. Sensitive information is masked.

In the product, trace and validation are part of the agent editor.
