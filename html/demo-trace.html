Demo

See every step an agent takes

This demo shows what a developer sees while building an agent. Ask for something, and search finds the agent built for it in a live Search2o account with 200 agents. The agent runs with tracing on and answers with mock data. Beside the answer are the agent’s description, which search matched your request against, its definition, and every step of the run.
