Description, indexed by search

A plain-language description of what the agent does. Search indexes this to match requests to agents — see search quality.

hr_policy · description
Answers employee questions about Acme Corp workforce policies: vacation and leave, benefits eligibility, remote-work rules, expense limits and the code of conduct. It explains what the policy says and where to find the form. It cannot approve requests, change records or make exceptions.
Hybrid architecture

Stateless agent servers. State managed in Search2o Cloud.

  1. User interface

    Users can submit requests from a browser, chat application, or agent skill. The browser UI also provides a complete workspace for agent development and system administration.

  2. Agent server

    A stateless server that runs standalone or in a cluster in your organization. Uses the agent framework to run agents in a controlled runtime. Encrypts sensitive information before it leaves the server. Source on GitHub.

  3. Search2o Cloud

    The shared service behind every agent server. The cloud provides platform services including search, state management, and reporting.

Built for the enterprise

Security & privacy

Secrets live in your vault. Sensitive information can be encrypted end to end. See how each kind of data is stored. Hooks help with custom policies.

Model neutrality

Bring your own keys. OpenAI, Anthropic, and Gemini are supported out of the box, along with any compatible LLM. Others need only a small adapter.

Operational continuity

Agent servers never need a restart. A change to configuration is live on the next agent run. A running agent keeps running with the old configuration.

API & automation

The agent server exposes a REST API. Use it to run non-interactive agent workflows — event-driven or in batch. The bundled GUI uses the same API.

Access & roles

Four roles: users, developers, administrators and owners. Service accounts for bots and scripts. Built-in authentication as well as single sign-on.

Reports

What ran, what failed, what it cost. Reports show trends in agent usage, performance, errors and LLM cost; each row opens the details.
