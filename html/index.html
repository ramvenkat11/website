Platform

Built for the enterprise

Security & privacy

Secrets live in your vault. Sensitive information can be encrypted end to end. See how each kind of data is stored. Hooks help with custom policies.

Access & roles

Four roles: users, developers, administrators and owners. Service accounts for bots and scripts. Built-in authentication as well as single sign-on.

Change control

An agent's LLM, API, database and MCP settings live in profiles, not its code. Every profile knows which agents use it. Every change is in the audit log.

Cost control

Each agent uses only the model its workflow needs, whether frontier, cheap or free. Every run has a spend limit, and reports show spend per agent and user.

Horizontally scalable

Agent servers are stateless and can be run in a cluster. Configuration and profile changes are live on the next agent run on every server, without restart.

API & automation

The agent server exposes a REST API. Use it to integrate Search2o with any other service, or to build any UI on top of it. The bundled GUI uses the same API.
