Agents written like a skill, validated like software

Describe what an agent should do in plain English, and Draft with AI writes it. The result is structured JSON with Python expressions, so developers can refine it in the schema‑aware code editor.

An agent runs as Python code with LLM calls, and it must pass validation before it is published. Profiles define enterprise systems and LLMs outside the agent, so dev and prod can differ. Prompts change without a new version.

Use agents where you already work

Every client uses the same two calls: search finds the right agent, and execAgent runs it. An authorization token identifies the user. The rest is up to the client.

A client can run the best match automatically or let the user choose. It can also use an LLM to split a request into parts and search for each part separately, as an agent harness does.

Stateless agent servers scale horizontally and stay in sync

An agent server is stateless: the cloud service provides state, search and reporting. Run one agent server or several in a cluster, and any agent server can serve any request.

A newly published agent, or a change to a profile or to the configuration, is live on the next agent run on every agent server.

Tactet agent platform

Built for enterprise operations

Security & privacy

Secrets live in your vault. Conversations and memories are encrypted, by default or, optionally, end to end. Data privacy lists how each kind of data is handled.

Identity & access

Four roles: users, developers, administrators and owners. Service accounts for bots and scripts. Built-in authentication as well as single sign‑on.

Change control

Agents are versioned. An audit trail shows every change to agents and configuration. A change is live on the next agent run on every server, without a restart.

Multiple environments

An agent refers to enterprise systems by profile name. Dev and prod profiles can point at their own systems, so the same agent runs unchanged.

Observability

Every agent run is recorded. Reports show agent performance, errors, LLM cost and usage. Reports break down by published version, so a regression stands out.

Integration

Integrate at three levels: from Python expressions inside an agent, through the REST API, and with hooks that run your code at the platform’s decision points.
