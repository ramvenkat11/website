Built for the enterprise

Security & privacy

Secrets live in your vault. Conversations and memories are encrypted by default. Everything that runs in your organization can be run from source.

Multi-user access and roles

Four roles: users, developers, administrators and owners. Service accounts for bots and scripts. Built-in authentication as well as single sign-on.

Model neutrality

Each agent picks its model. Out of the box: OpenAI-compatible models, Anthropic, Gemini, Ollama, vLLM and SGLang. Adapters can be added for other LLMs.

Observability & cost

Every run records its cost, time and result, failures included. Reports show cost, errors, performance and usage per agent and user. Every run has a spend limit.

Horizontally scalable

Agent servers are stateless and can be run in a cluster. Configuration and profile changes are live on the next agent run on every server, without restart.

Integration

Integrate at three levels: from Python expressions inside an agent, through the REST API, and with hooks that run your code at the server's decision points.
