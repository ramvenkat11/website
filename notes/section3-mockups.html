Frontier models from OpenAI, Anthropic and Google. Free, open models on your own machines through Ollama, vLLM and SGLang. Any other LLM with an adapter.

  1. 1Written from a sentenceDraft with AI wrote this file from "answers questions about orders". Validation ran it once with a full trace. Publishing gave it a version and a description that search indexes.
  2. 2One line calls your APIThe host, credentials, headers, connection pool and error handling come from the orders profile. The agent holds only the path. Databases and MCP servers work the same way.
  3. 3Any modelThe profile names the model and holds the key. Six adapters are bundled, for frontier and free models. Try the buttons.
  4. 4Prompts live outside the codeThe prompt is written and changed in the UI, so a wording change is not a code change. Prompts
  5. 5The tool loop is the server's jobThe model calls getOrder as often as a question needs. The server runs each call and feeds the result back. Tool calling
  6. 6Everything after the answerThe answer streams to the client. The conversation is saved for the next turn. Limits, guardrails, the audit log and the cost report need nothing from the agent. Runtime

What the server doeswithout a line from you
1
Develop

Draft with AI writes the first version from a sentence. The editor knows every command and points out mistakes as you type. Validation runs the draft and shows the trace.

2
Publish

One click gives the agent a version and a plain-English description. Search indexes it, and users find it by asking.

3
Run

Search picks the agent. The server calls the model you named: OpenAI, Anthropic, Gemini, or a free model you host with Ollama, vLLM or SGLang. Change the model by changing the name.

It holds the secrets, pools the connections, loops the tool calls, streams the answer, saves the conversation, and enforces the limits and guardrails. Every run is traced, audited and reported.
